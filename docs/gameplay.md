# 玩法設定（v0.2）

> 配套文件：`requirements-and-feasibility.md`（技術鏈路）。
> 原則：**玩法主導技術鏈路**；只有在 Vibe Coding 很可能失敗時才砍玩法。

| # | 項目 | 決定 |
|---|---|---|
| 1 | 核心目標 | **純自由沙盒**：沒有劇情，沒有強制進度。初衷是「市面上沒有真正自由的賽車遊戲」 |
| 2 | 賽事 | 不做正式賽事系統；做**輕量自由工具**（無獎勵、無進度）：即時極速 / 漂移分數 / 飛躍距離統計；**自訂計時賽**：地圖上任設起點與終點，可與重播幽靈車對比 |
| 3 | 對手 | 不做 AI 對手；NPC 交通車仍為可選 |
| 4 | 車輛陣容 | **每個大類一台**，全部原創，首版 9 台（見下表）；**機車暫不做**，日後視需求決定 |
| 5 | 性能自定義 | **不做「換引擎」零件系統，玩家直接調整引擎數值**；懸掛、齒比等調校同樣開放。日後可加回零件系統。兩種模式：**物理代價模式（預設）**——馬力越大引擎越重、越耗油，紅線受排量與汽缸數限制；**解除限制模式**——滑桿完全自由 |
| 5b | 動力類型 | 本版只有內燃機；**電動車暫不做**，日後可能加入（屆時需生成充電站） |
| 6 | 外觀 | 顏色、材質（金屬漆/珠光/啞光）可改；輪距等車身比例在難度不高時開放；**拉花貼紙本版不做** |
| 7 | 損壞 | 三檔可選：① 無損壞（外觀也不變）② 僅外觀損壞 ③ 外觀 + 一定程度的性能損壞 |
| 8 | 世界互動 | 部分小物件可撞飛（路牌、護欄、路錐、紙箱等）；**樹與樹枝不可撞斷**；本版不做收集要素；**不做警察** |
| 9 | 季節 | 玩家可自行調整 |
| 10 | 視角 | 以車外第三人稱為主，主視角參考地平線：車後方、略高 |
| 11 | 擬真元素 | 不做輪胎磨損、胎溫、方向盤外設；**做油耗**（可關閉，且世界生成必須保證加油站分佈合理）；**手動換擋、無離合**，設定中可切換自動擋 |
| 11b | 操作 | 電腦：鍵盤 + 滑鼠。手機：觸屏 + 螢幕 UI，轉向**預設左右按鈕**，可在設定中改為**陀螺儀傾斜轉向**；不做虛擬方向盤與滑桿 |
| 11c | 下車 | 不做（不能下車走路） |
| 12 | 世界 | 類似 Minecraft：預設一張「官方世界」，可用隨機或自定義種子生成新世界；**生成時可選大小：小 / 中（約 100 km²，官方世界）/ 大** |
| 13 | 音樂 | CC0 曲庫車載電台，可關閉 |
| 14 | 重播 | 做；物理必須每次結果一致（確定性物理） |

## 由玩法推出的技術要求
- **引擎參數化**：引擎由參數描述（排量、汽缸數與排列、紅線、進氣方式/增壓值、扭矩曲線形狀等），由參數計算扭矩曲線、油耗與重量。**引擎聲同樣由這些參數程序合成**，汽缸數和轉速不同，聲音自然不同。
- **加油站生成規則**：沿路網放置；每座城鎮至少一座；在主要道路上，任何位置到最近加油站的行駛距離不超過上限（暫定 15 km）；油量 UI 與 GPS 可以搜尋最近的加油站。
- **損壞三檔**：損壞做成狀態數據（每個部位的損壞值），渲染（凹陷變形、刮痕）和物理（轉向偏移、功率下降）讀取同一份數據。
- **可撞飛物件**：輕量剛體，由程序化生成器放置；離開視野一段時間後重置。
- **季節**：植被（葉色、落葉、光禿枝幹）、地面（積雪覆蓋、枯草）、路面摩擦（雪/冰）都由一個「季節參數」驅動。
- **多世界**：所有世界數據由種子確定生成；存檔只存種子、玩家位置、車輛配置和設定。
- **世界大小可選**：聚落數量、間距上下限和加油站數量按世界面積縮放，保證小世界和大世界的城鄉比例都是三七開。
- **拖車**：牽引點用鉸接約束連接，拖車有獨立的輪子和懸掛；需要支援倒車（拖車折角）與脫鉤 / 掛鉤。
- **自訂計時賽**：在地圖上放置起點、終點和可選檢查點；用重播系統錄下最佳成績，作為幽靈車回放。
